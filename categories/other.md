## Overview

A holding place for well-known repositories that the catalogue cannot file anywhere else.

- **What goes here:** a repository found through GitHub whose topics name no category above.
- **What it holds:** the facts GitHub gives (description, language, licence, stars), nothing written by hand.
- **Why it exists:** a repository is never filed by guess, so it waits here instead.

## Notes

- A repository moves to a real category once its topics, or a reviewer's judgement, name one.
- This category has no default choice and no ranking; it is not a recommendation.
